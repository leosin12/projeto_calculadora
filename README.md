# Projeto Calculadora - FinançApp

Projeto desenvolvido para a disciplina de UX/UI e Testes de Software, com o objetivo de criar uma calculadora em Java utilizando boas práticas de versionamento com Git, refatoração de código, tratamento de exceções e documentação Javadoc.

## 🛠️ Tecnologias e Ferramentas
* **Java** (JDK 17+)
* **Eclipse IDE**
* **Git e GitHub**
* **Javadoc** (para documentação)

## 📁 Estrutura do Projeto
O projeto está organizado na seguinte estrutura de pastas:
```text
projeto_calculadora/
├── src/
│   └── calculadora/
│       ├── Calculadora.java       # Classe principal com as operações matemáticas
│       └── TesteCalculadora.java  # Classe de testes e execução
├── docs/                          # Documentação gerada pelo Javadoc
└── README.md                      # Documentação do projeto
